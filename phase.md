# Project Files

| File                   | Responsibility                                         |
| ---------------------- | ------------------------------------------------------ |
| `app/main.py`          | Creates and configures the FastAPI application         |
| `app/core/config.py`   | Reads and validates application settings               |
| `app/api/v1/health.py` | Defines the health-check endpoint                      |
| `.env`                 | Stores your local environment configuration            |
| `.env.example`         | Documents required environment variables               |
| `.gitignore`           | Prevents secrets and generated files from entering Git |
| `requirements.txt`     | Records Python dependencies                            |
